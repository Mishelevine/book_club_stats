# Рекомендации от редакции

Одностраничник читательского клуба Миши, Вари, Юли и Димы. Текущая книга, общий топ, история чтения, редакционные подборки и статистика. Статический сайт для GitHub Pages, без сервера, регистрации и установленных библиотек.

## После каждой встречи

Все книги и оценки находятся в **`data/books.json`**. Дизайн и расчёты трогать не нужно.

1. Открой `data/books.json` в GitHub, нажми кнопку редактирования с карандашом.
2. Найди обсуждённую книгу. Поставь `"status": "read"`, в `finishedAt` укажи дату встречи, например `"2026-11-07"`.
3. Заполни `pages` по вашему изданию и `suggestedBy`: `"misha"`, `"varya"`, `"yulia"` или `"dima"`.
4. В `ratings` поставь каждому `stars` от `0.5` до `5` с шагом `0.5`. Для дробей используй точку: `4.5`. В `text` можно написать короткий отзыв или оставить `""`.
5. Если кто-то ещё не оценил книгу, оставь `"stars": null`. Это не ноль и не снижает рейтинг.
6. Сохрани изменения кнопкой **Commit changes** в ветку `main`. После успешного запуска публикации сайт обновится.

«Цветы для Элджернона» обсуждены 18 октября 2026 года: Миша — 4,5, Варя, Юля и Дима — по 4 из 5. Сейчас читаем «Трудно быть богом». Предложившие участники и объёмы изданий пока не указаны.

## Добавить следующую книгу

Загрузи её обложку в папку `assets/`: подойдут JPG, PNG, WebP или SVG. Лучше вертикальное изображение, примерно 2:3. Название файла — латиницей без пробелов, например `next-book.jpg`. Обложки хранятся вместе с сайтом: внешние книжные сервисы не нужны. У первой книги своя декоративная SVG-обложка сайта, а не скан конкретного издания.

Скопируй этот шаблон в массив `books`. Между объектами книг нужна запятая; после последнего объекта запятая не нужна. Пример ниже — именно шаблон, а не настоящие сведения о прочитанной книге.

```json
{
  "id": "next-book",
  "title": "Название книги",
  "author": "Имя автора",
  "cover": "assets/next-book.jpg",
  "pages": null,
  "suggestedBy": null,
  "status": "reading",
  "finishedAt": null,
  "ratings": {
    "misha": { "stars": null, "text": "" },
    "varya": { "stars": null, "text": "" },
    "yulia": { "stars": null, "text": "" },
    "dima": { "stars": null, "text": "" }
  }
}
```

`id` уникальный, латиницей с дефисами. Для новой текущей книги используй `reading`; для уже прочитанной — `read`. Обычно текущая книга одна: предыдущую сначала переведи в `read`. Если текущих несколько, верхняя карточка покажет первую из файла, а дневник — все.

Неизвестные `pages`, `suggestedBy` и `finishedAt` можно оставить `null`. Для `reading` дата завершения всегда `null`. Внутри текста кавычки нужно записывать как `\"` или использовать «ёлочки». Перенос строки внутри отзыва — `\n`.

## Как считаются результаты

- **Топ:** только прочитанные книги хотя бы с одной оценкой. Среднее доступных оценок, без округления при сортировке. На экране — один знак после запятой и число голосов. Равный рейтинг даёт общее место; все книги, разделяющие третье место, остаются в топе.
- **Порядок блоков:** до первых оценок верхнюю позицию занимает текущая книга. Когда появляется рейтинг, топ поднимается наверх, а текущее чтение становится компактнее и идёт следом.
- **История:** текущие книги, затем завершённые от новой встречи к старой. Книги без даты в конце. Порядок объектов в файле на хронологию завершённых книг не влияет.
- **Самая спорная:** самая большая разница между максимальной и минимальной оценкой. Требуются хотя бы две разные оценки. При равенстве показываются все такие книги. Это показатель разницы голосов, не утверждение о реальном споре на встрече.
- **Единодушно рекомендуем:** каждый участник поставил не меньше четырёх звёзд. Без голоса одного участника книга сюда не попадает.
- **Вкус редактора:** книги с самой высокой личной оценкой участника среди завершённых. При равенстве показываются все любимые.
- **Книги и страницы:** только завершённое чтение. Объём книги учитывается один раз, а не умножается на число участников. Если объём не указан, есть подпись о недостающих данных. Когда объём неизвестен у всех завершённых книг, вместо страниц стоит прочерк.
- **Средняя оценка клуба:** среднее всех личных оценок завершённых книг. Каждая выставленная оценка имеет одинаковый вес.
- **Кто чаще выбирает:** количество завершённых книг, предложенных участником. Неизвестный предложивший участник не учитывается. При равенстве перечисляются все лидеры.

Текущая книга не участвует в статистике или подборках, даже если у неё уже введены оценки.

## Посмотреть локально

Нужны Node.js 22+ и Python 3. Установка зависимостей не требуется.

```sh
npm test
npm run build
npm run preview
```

Открой `http://127.0.0.1:4173`. Остановка — Ctrl+C. После изменения исходников повтори `npm run build` и обнови страницу. Открытие `index.html` двойным щелчком не подойдёт: браузер должен загрузить файл с данными по HTTP.

`npm run check` отдельно проверяет данные и наличие обложек. Сборка выполняет эту же проверку до подготовки `dist/`; `dist/` не редактируется и не хранится в Git.

## Включить GitHub Pages

Для репозитория `Mishelevine/book_club_stats`:

1. Загрузи файлы проекта в ветку `main`.
2. Открой **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Открой **Actions → Publish book club → Run workflow**, выбери `main` и запусти публикацию. Следующие изменения в `main` публикуются автоматически.
4. Дождись успешного завершения обоих этапов. Ссылка появится в окружении `github-pages` и настройках Pages.

Ожидаемый адрес: `https://mishelevine.github.io/book_club_stats/`. Адрес считается опубликованным только после успешного завершения Actions. Для бесплатного GitHub Pages нужен публичный репозиторий; доступность для закрытых репозиториев зависит от тарифа.

Публикуется только `dist/`, без исходных тестов и инструкции. Все ссылки на файлы относительные: сайт работает в подпапке репозитория. Если проверка завершилась с ошибкой, исправь данные по сообщению в Actions — новая версия не заменит предыдущую рабочую.

Официальные инструкции: [публикация через GitHub Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Оформление

Кремовый фон, лесной зелёный акцент `#496653` и спокойный Onest с кириллицей для заголовков и основного текста. Шрифт загружается из Google Fonts; если сервис недоступен, используется системный шрифт. Обложки и все данные локальные. Цвета и шрифты задаются в начале `styles.css`.

Пиксельная книжечка — собственный маскот клуба. В шапке используется `assets/book-mascot.gif`: небольшое покачивание и короткое моргание примерно раз в семь секунд. При системной настройке уменьшения движения браузер выбирает статичный `assets/book-mascot.png`. Он же используется для иконки вкладки. [Описание, запросы для генерации и пересборка GIF](docs/book-mascot.md). Горизонтальные разделители стоят только между крупными разделами; декоративных номеров и символов Claude нет.
